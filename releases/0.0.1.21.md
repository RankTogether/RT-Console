# RT Console 0.0.1.21

- 修复 Windows 打开 MCAP 后进度停在 100%：后台完成通知改由播放器自己的 UI 调度窗口接收，不再依赖 Flutter 主窗口的挂接顺序；读取失败也能正确返回界面。
- 修正文件选择器与全屏操作的宿主窗口，保留上一版本的正常关闭保护。
- 索引完成后明确显示“正在整理录像信息”，收到打开结果后才进入回放；慢进度查询不再重复堆积。
- Windows 安装版与便携版新增真实界面导入检查，覆盖有效文件、损坏文件反馈，以及视频消息偏移超过 4 GiB 的稀疏文件，并核对首帧、时间数据返回和正常退出。
- Ubuntu、Windows、Android 统一版本；安装身份保持兼容，演示素材继续暂缓。

本版本沿用预发行渠道；本标签的 Actions 执行三平台构建、包校验与 Windows 导入门禁。稀疏文件验证大偏移读取，不等于所有超长实录的性能或内存验收。真实 Windows LAN / BLE、现场原大文件及 Android 手机回放仍需现场验证。Android APK 为 internal-debug 签名，macOS 暂缓。
