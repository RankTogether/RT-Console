# RT Console 0.0.1.28

私有预发行候选，统一 Ubuntu x64 / Windows x64 / Android arm64 版本。

- 设备页与数据回放统一公司 VI、官方字标、蓝绿配色及新启动图标；突出连接状态和“打开网页”。
- 修复 Ubuntu USB IPv6 link-local 请求失败，按可用路径汇总连接状态；浏览器打开前核对普通路由和设备身份，增加备用启动方式，成功提示约 3 秒自动消失。
- 修复 Windows 最小 FFmpeg 构建的 D3D11VA / D3D11VA2 对象选择，保留 H.264 / HEVC 的自动硬解与软件回退。
- 修复 Windows 验证原生中文状态时误用系统代码页的失败，原生 C++ 与四组协议验证显式使用 UTF-8；缓存已完成的原生依赖以便续办。
- 修复 Windows 解码模式切换的完成通知参数，保持异步错误能够回到原请求。
- 降低稳定设备的刷新频率，重复发现广播去重，隐藏设备页暂停常规查询。
- MCAP 联动保留同步原图、头环姿态、相机选路、IMU 与时间分析；头环默认编号统一为屏幕左→右 345210，默认正向略俯视。
- Ubuntu 随包提供图像辅助姿态与联合位置轨迹组件；位置计算仍要求录制内标定、适用的 IMU / 时间依据。安装包不携带用户录像或本机依据。Windows / Android 本候选未打包这些可选 worker，可查看视频与 IMU 头环姿态。
- 全景融合、精度叠加与曝光中心选项继续暂停；不新增真实姿态、标定或位置精度验收结论。

三平台构建、软件回归、包校验和桌面安装启动由本次 CI 记录；现场无线、Android 手机、长录像性能及真实轨迹精度仍需独立验收。Windows 尚未代码签名；Android 为 internal-debug 签名，升级须匹配原安装签名。macOS 暂缓。此候选只发布到私有仓。
