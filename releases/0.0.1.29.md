# RT Console 0.0.1.29

新增 MCAP 磁编码器（MGE）夹爪角度浏览与记录时间对照；三平台统一版本，作为 GitHub 私有库内部测试候选。

- 回放页在 IMU 旁保留 MGE 入口，文件没有可浏览的 MGE 角度通道时置灰；各来源显示度 / rad，跟随播放与定位，保留样本质量及时间来源。
- “时间”页加入 MGE 绿色菱形、参考视频帧的最近记录时间差、原始纳秒与前后邻点；多通道紧凑显示，缺失不补零，纯 MGE 文件也可查看。
- 修复 MGE 原生查询公共字段缺失和连续播放时读数闪空；历史 RAW 不自动换算，双爪夹角不重复乘二。
- Android 包含 App 内设备网页及其文件下载 / 回放衔接，沿用设备列表“打开网页”；外部浏览器保留。
- 候选构建依次验证 Windows、Ubuntu、Android，全部通过后冻结私有 Release。

Ubuntu 包含可选图像姿态 / 位置组件；Windows / Android 未打包这些组件。Windows 尚未代码签名，Android 为 internal-debug 签名；包构建、安装启动与真实无线 / 手机 / 录像性能及物理同步精度分别验收。MGE 承载帧时间不代表独立采样同步精度。
