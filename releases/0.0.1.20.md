# RT Console 0.0.1.20

一个客户端完成设备管理与本地 MCAP 视频 / IMU 回放，Ubuntu、Windows、Android 共用四位版本。

- 安装包统一采用 `rt-console_版本_平台`，Ubuntu 后缀为 `.deb`；三平台打包、校验及 CI 共用 `product.json` 的名称配置。保留安装身份，可覆盖升级。
- 发布仓库迁移至 [RankTogether/RT-Console](https://github.com/RankTogether/RT-Console)，沿用原安装身份和版本序列。
- 修正 Windows 播放器插件关闭时访问已销毁引擎的消息接口，并保护销毁期间的窗口消息；保留正常关闭退出检查。
- 修正 Windows Flutter 插件 junction 路径下的依赖定位，应用编译与 FFmpeg DLL 打包使用同一真实客户端根目录。
- 固定布局资源原始字节，避免 Windows 换行转换破坏 SHA256；调整 Windows 原生插件头文件顺序。
- 应用名称统一为 RT Console，沿用原安装身份，Ubuntu 只保留一个可见应用入口；设备管理和数据回放位于同一主窗口。
- 支持本地 H.265 / H.264 MCAP 视频、IMU 曲线与原始纳秒时间检查；视频 / IMU 共用时间轴，可观察相机帧差、邻近 IMU 样本及采样间隔。
- 新头环俯视图从右起相机 0、1、2、5、4、3，点击六个热点切换对应视频。IMU 0 / 1 对应 Link A / B 的 imu0，安装点未确认时保留独立图例。
- 支持配套 Jetson 0.0.1.42 的 MCAP v4 布局快照与公开编号；历史文件依自己的合同读取，未知 / 冲突布局保留数据并显示诊断，不重排标定。
- Linux 使用规范桌面入口关联与稳定视频纹理生命周期，改善最大化 / 标题栏双击时的显示闪烁。
- 沿用局域网发现、设备命名 / 完整 UUID、网络 / BLE Wi-Fi 配网、设备定位与统一固件版本显示。
- 演示素材暂缓，本版不内置录制文件。没有样本时显示待补充，用户可打开自己的 MCAP 文件。

本版本作为预发行提供。三平台构建 / 打包检查由本标签的 GitHub Actions 执行；构建成功不等于真实 Windows LAN / BLE 或 Android 手机无线与回放验收。此前 Ubuntu 本机已安装 .17；本轮按用户要求不在本机追加测试。

桌面 H.264 / H.265 使用私有 FFmpeg 软件解码，Android 使用系统 MediaCodec，实际性能和编码支持由设备决定。Android APK 仍为 internal-debug 签名，覆盖已有本地签名包可能需要先卸载；macOS 暂缓。时间戳可视化不作为物理同步或标定精度认证。
