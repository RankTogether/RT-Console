# RT Console 0.0.1.34

三平台预发行候选，范围：Windows x64 / Ubuntu x64 / Android arm64。

- 完成 `rtcamera-finder` 到 `rt-console` 的包名、二进制名、桌面入口、Windows 安装器注册表清理及 Android 应用包名（`com.ranktogether.rt_console`）统一改名；Ubuntu deb 声明替代旧包 `rtcamera-finder`，Windows 安装器保留原 `AppId` 覆盖升级并清理旧可执行文件与旧 ProgID。
- 优化 Windows / Ubuntu 设备发现稳定性与系统浏览器拉起：Windows 改为按网卡独立管理 browse 与路由过滤、临期定向重解析；Ubuntu GUI 优先通过 GTK 窗口激活上下文打开浏览器；发现协调器增加瞬态容错与主动重发现，支持桌面失焦持续刷新与 Windows WPA3-SAE 识别。
- 扩展本地回放对公共 MCAP 格式（`rtcamera.public` / `rtcamera.attachments` / `calibration.json`）及 IMU / MGE 质量字段的支持。
- 统一跨平台许可证与 NOTICE 文本附件为 LF 换行，避免 Windows 与 Ubuntu / Android 候选冻结阶段因换行差异冲突。

平台构建、包校验与桌面安装 / 回放冒烟由本版本 CI 报告记录；Ubuntu 随包包含可选姿态 / 位置 worker，Windows / Android 不打包这些可选组件。Windows 安装器尚未代码签名，Android 为 internal-debug 签名（首次从旧包名切换需先卸载旧测试包），macOS 暂缓。真实 LAN / BLE / Wi-Fi、GPU 硬解、物理手机及长录像性能与精度须独立验收。
