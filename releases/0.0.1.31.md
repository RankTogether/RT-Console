# RT Console 0.0.1.31

Windows x64 预发行。本次仅提供 Windows 安装版、便携版及其验证 / 校验文件。

- 支持新 Jetson 公共 MGE / IMU 命名及八相机布局 revision 3，继续兼容旧物理通道名；MGE 以 rad 显示双爪夹角。
- 按实际录入的视频、IMU、MGE 显示通道，支持零视频与部分传感器录制；没有 MGE 角度时入口置灰，并显示文件提供的原因。
- 头环使用 EGO 相机与姿态来源；手部 camera6/7 保留视频回放，明确的手部 IMU 不再驱动头环。
- 文件信息展示有序采集分组与传感器关联，隔离无效、重复或超大的可选附件，保持正常测量读取及标定资格判断。
- 发布入口支持单独构建和发布 Windows，私有候选与公开附件固定同一源码、范围及文件哈希。

Windows 安装器未代码签名，不含可选图像辅助姿态 / 位置 worker。构建、安装与回放冒烟由本版本 CI 报告确认；真实 LAN / BLE、GPU 硬解、长录像性能与测量精度须独立验收。传感器关联和录制时间戳不等同于几何标定或同步精度认证。
