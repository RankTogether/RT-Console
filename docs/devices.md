# 连接与管理设备

## 配置 Wi-Fi

配置 Wi-Fi 时可从电脑附近网络选择，默认电脑当前 SSID，也可手填；密码自行输入。刷新不覆盖已编辑名称，选择不同名称会清空原密码。“隐藏网络”在高级选项中，仅用于路由器不广播名称的 Wi-Fi。

点击连接后持续显示任务状态；看到“Wi-Fi 已连接，尚未保存”时点击“确认保留网络配置”，等待“Wi-Fi 已保存”才算完成。失败与结果未知会单独提示；蓝牙失联后不自动重复写入，关闭后可重新连接查看设备现状。蓝牙扫描前会检测并尝试开启蓝牙；无法开启时按系统提示处理。

等待确认保存时不显示加载动画，后台仍查询原任务的期限和最终结果。0.4.11 还将后台查询与前台按钮状态分开，保存按钮不随查询反复变灰；查询期间也能点击，点击后禁用重复操作，等查询返回再核对是否仍可保存。收到设备确认前不会冒充成功，查询失败或任务过期不会继续发送保存。实际保存时持续显示“正在保存 Wi-Fi”及进度条，收到设备 DONE 后结束。此修正仅需更新 Finder，设备协议不变。

使用配套新版设备软件时，选择目标设备、连接并填写 Wi-Fi 后即可点击“连接 Wi-Fi”，无需长按按键或运行 USB 授权命令；不依赖 GMSL。录制期间仍拒绝修改网络，请先停止录制。旧设备返回 `WINDOW_CLOSED` 或旧版授权过期时明确提示升级设备软件；新版设备会话过期则提示重新连接。保留已填内容，不自动重试。

发行包从 [Releases](https://github.com/RankTogether/RT-Console/releases) 获取。Windows 使用 Native WLAN 查询电脑 SSID；位置权限或驱动拒绝时可手填，刷新尚未确认时明确标注系统缓存。

## 搜索与打开

1. 电脑与 Hub 至少一张网卡处于可互通网络；例如两者连接相同 Wi-Fi，即使 Hub 的另一条网线不通也能使用 Wi-Fi 路径。
2. 打开程序自动搜索，按完整设备 ID 区分设备。支持的设备可用铅笔按钮修改名称；清空恢复默认名。
3. 点击“打开网页”。客户端会按系统普通路由再次核对身份，防止 DHCP 换址或相同 USB 子网误选设备。

未接 GMSL 不影响发现，状态可显示为虚拟或未知。搜索依赖网络允许 mDNS；跨 VLAN、AP 隔离、VPN 和主机防火墙可能阻断它。可手工添加已知 IP，默认管理端口 8766；客户端不扫描网段或重配网络。Windows 使用系统原生 DNS-SD，无需安装 Bonjour。

同包提供命令行程序（Windows 名称带 `.exe`）：

```sh
rtcamera-finder-cli --duration 10
rtcamera-finder-cli --manual 192.168.55.1:8766 --duration 3
rtcamera-finder-cli --duration 5 --open --dry-run
```

`--open` 仅在恰好一个设备行时打开；`--dry-run` 输出已复核的 URL。IPv6 link-local 路径可探测，暂不自动交给浏览器。
